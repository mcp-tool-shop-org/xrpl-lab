Usage: xrpl-lab verify-artifact [OPTIONS] FILE

  Verify any XRPL Lab JSON artifact: its embedded integrity hash, or a support
  bundle's structure (it carries no hash).

  Auto-detects the artifact kind from its own JSON markers, then runs the SAME
  verification as that kind's (now deprecated) native command:

      proof pack       xrpl_lab_proof_pack marker
      certificate      xrpl_lab_certificate marker
      audit pack       tool="xrpl-lab" + verdicts (integrity_sha256)
      support bundle   schema="xrpl-lab-support-bundle-v1"

Options:
  --json  Machine-readable JSON output
  --live  Ledger-anchored verification for a proof pack (and a certificate):
          re-fetch every claimed txid from the public XRPL and confirm it is
          there as claimed. The offline SHA-256 check ALWAYS runs; --live adds
          the on-ledger trust layer. Audit packs and support bundles have no
          on-ledger check, so --live says so and changes nothing.
  --help  Show this message and exit.
