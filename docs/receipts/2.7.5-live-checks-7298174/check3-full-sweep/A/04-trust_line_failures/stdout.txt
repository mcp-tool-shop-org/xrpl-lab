Most "why won't this token work?" questions come down to one thing: the trust line.                                                                            

In this module you intentionally break a token transfer — then read the failure, fix it, and confirm the fix on-ledger. Breaking things on purpose is the      
fastest way to learn what the error codes actually mean.

new issuer would orphan trust lines (and their owner reserve) against the previous address. Leftover lines from earlier currencies still lock reserve until    
balance is 0 and you remove them; run Account Hygiene (account_hygiene) for the taught cleanup loop.

Press Enter to continue...Attempt to receive tokens WITHOUT a trust line                                                                                                                 

This is the key moment. The issuer will try to send you 100 DBG tokens. But you have not set a trust line for DBG — so the ledger has no permission to deliver 
them.                                                                                                                                                          

Watch for the error code. On the XRPL, this is tecPATH_DRY: the payment has no valid delivery path because the destination has no trust line for this currency.

Press Enter to continue...What you proved                                                                                                                                                

You just debugged the most common trust line failure:                                                                                                          

 1 No trust line → tecPATH_DRY — the ledger refuses to deliver tokens you did not agree to receive                                                             
 2 Set trust line → you opted in to holding DBG from this issuer                                                                                               
 3 Reissue → same payment, now succeeds                                                                                                                        
 4 Verified → the trust line and balance are correct on-ledger                                                                                                 

When a token transfer fails, check the trust line first. The error code tells you exactly what is missing, and the fix is always the same: set the trust line, 
then retry.                                                                                                                                                    

Common trust line failures you'll encounter in the wild:                                                                                                       

 • tecPATH_DRY — no delivery path (missing trust line or no liquidity)                                                                                         
 • tecNO_LINE — destination has no trust line for this currency                                                                                                
 • tecNO_DST — destination account does not exist                                                                                                              
 • tecUNFUNDED_PAYMENT — sender does not have enough of the token
