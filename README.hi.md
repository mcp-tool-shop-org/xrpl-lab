एक्सआरपीएल प्रशिक्षण कार्यपुस्तिका – करके सीखें, और अपने कौशल का प्रदर्शन करें।

प्रत्येक मॉड्यूल एक एक्सआरपीएल कौशल सिखाता है और एक सत्यापित परिणाम उत्पन्न करता है: एक लेनदेन आईडी, हस्ताक्षरित रसीद या एक नैदानिक रिपोर्ट। इसमें कोई खाता नहीं, कोई अनावश्यक जानकारी नहीं, और क्लाउड का उपयोग भी नहीं किया जाता – केवल दक्षता और रसीदें ही शामिल हैं।

</p>

## स्थापित करें।

```bash
pipx install xrpl-lab
```

या पिप का उपयोग करके:

```bash
pip install xrpl-lab
```

इसके लिए पायथन 3.11 या उससे ऊपर के संस्करण की आवश्यकता है।

## त्वरित शुरुआत

```bash
xrpl-lab start
```

गाइडेड लॉन्चर आपको वॉलेट सेटअप, धनराशि जमा करने और आपके पहले मॉड्यूल के बारे में मार्गदर्शन करता है।

### ऑफ़लाइन मोड

```bash
xrpl-lab start --dry-run
```

किसी नेटवर्क की आवश्यकता नहीं है। कार्यप्रणाली सीखने के लिए नकली लेनदेन का उपयोग किया जा सकता है।

**उत्पाद** नामक स्तंभ में प्रत्येक मॉड्यूल द्वारा उत्पन्न किए जाने वाले कलाकृतियों के प्रकारों की सूची दी गई है (`txid`, `रिपोर्ट`, `ऑडिट_पैक`); प्रत्येक मॉड्यूल के पृष्ठ को [हैंडबुक](https://mcp-tool-shop-org.github.io/xrpl-lab/handbook/modules/) में देखें, जिसमें पूरी प्रक्रिया और लेज़र पर आप जो साबित करते हैं, उसका विवरण दिया गया है।

### पटरियाँ/रेल की लाइनें

- **आधारभूत अवधारणाएं** – वॉलेट, भुगतान, भरोसेमंद संबंध, त्रुटि प्रबंधन
- **एनएफटी** – एनएफटी गेम संपत्ति: निर्माण, बाज़ार में निपटान, गतिशील एनएफटी (एक्सएलएस-20)
- **टोकन** – बहुउद्देशीय टोकन (एमपीटी) गेम-मुद्रा जारी करना और वापस लेना (एक्सएलएस-33)
- **भुगतान** – एस्क्रो और समय-आधारित मूल्य
- **पहचान** – विकेंद्रीकृत पहचानकर्ता (डीआईडी, एक्सएलएस-40)
- **डेक्स** – प्रस्ताव, ऑर्डर पुस्तकें, बाजार निर्माण, इन्वेंट्री प्रबंधन
- **आरक्षित निधि** – खाता आरक्षित निधि, मालिक की संख्या, सफाई
- **लेखापरीक्षा** – बैच सत्यापन, लेखापरीक्षा रिपोर्ट
- **एएमएम** – स्वचालित बाजार निर्माता तरलता, डेक्स बनाम एएमएम तुलना
- **कैपस्टोन** – विभिन्न ट्रैकों से कौशल को मिलाकर एक गेम-अर्थव्यवस्था का निर्माण करें

### तरीके/विधियाँ

- **टेस्टनेट** – एक्सआरपीएल टेस्टनेट पर वास्तविक लेनदेन।
- **ड्राई-रन** – नकली लेनदेनों के साथ ऑफ़लाइन सैंडबॉक्स (किसी नेटवर्क की आवश्यकता नहीं)।

## कार्यशाला में उपयोग के लिए।

एक्सआरपीएल लैब को वास्तविक शिक्षण वातावरण के लिए डिज़ाइन किया गया है। इसमें कोई खाता, टेलीमेट्री या क्लाउड शामिल नहीं है। सब कुछ स्थानीय रूप से चलता है।

<p align="center">
  <img src="https://raw.githubusercontent.com/mcp-tool-shop-org/xrpl-lab/main/docs/images/facilitator-active-runs.png" width="800" alt="Facilitator dashboard listing active learner runs with module IDs, dry-run badges, status, queue depth, and run IDs">
</p>

### सुविधाकर्ता स्थिति

```bash
xrpl-lab status             # Where is this learner? What's blocked? What's next?
xrpl-lab status --json      # Machine-readable for scripting
xrpl-lab tracks             # Track-level completion: what was actually practiced
xrpl-lab recovery           # Stuck? See exactly what to run next
```

### सहायता हस्तांतरण

```bash
xrpl-lab support-bundle              # Human-readable markdown bundle
xrpl-lab support-bundle --json       # Machine-parseable JSON
xrpl-lab support-bundle --verify bundle.json  # Verify a received bundle
```

एक सुविधाकर्ता किसी भी शिक्षार्थी की समस्या का निदान, पूरे सत्र को दोहराए बिना, एक सहायता बंडल से कर सकता है। इसमें कोई गुप्त जानकारी शामिल नहीं है।

### कार्यशाला प्रवाह

**पूरी तरह से ऑफ़लाइन सैंडबॉक्स** - किसी नेटवर्क की आवश्यकता नहीं:
```bash
xrpl-lab wallet create
xrpl-lab start --dry-run
```

**मिश्रित ऑफ़लाइन + टेस्टनेट** - बुनियादी बातों के लिए वास्तविक लेनदेन, उन्नत कार्यों के लिए सैंडबॉक्स:
```bash
xrpl-lab wallet create
xrpl-lab fund
xrpl-lab start
```

**कैंप → लैब प्रगति** - एक्सआरपीएल-कैंप से जारी रखें:
```bash
xrpl-lab start    # auto-detects camp wallet and certificate
```

## कलाकृतियाँ

**प्रमाण पैक** (`xrpl_lab_proof_pack.json`): पूर्ण किए गए मॉड्यूल, लेनदेन आईडी और एक्सप्लोरर लिंक का साझा करने योग्य रिकॉर्ड। इसमें SHA-256 अखंडता हैश शामिल है। कोई गुप्त जानकारी नहीं।

**प्रमाणपत्र** (`xrpl_lab_certificate.json`): संक्षिप्त समापन रिकॉर्ड।

**रिपोर्ट** (`reports/*.md`): आपने जो किया और साबित किया, उसका मानव-पठनीय सारांश।

**ऑडिट पैक** (`audit_pack_*.json`): SHA-256 अखंडता हैश के साथ बैच सत्यापन परिणाम।

## सुरक्षा और विश्वास मॉडल

**एक्सआरपीएल लैब द्वारा उपयोग किए जाने वाले डेटा:**
- वॉलेट सीड (स्थानीय रूप से `~/.xrpl-lab/wallet.json` में सादे पाठ JSON के रूप में संग्रहीत, 0o600 फ़ाइल अनुमतियों और 0o700 मूल निर्देशिका द्वारा सुरक्षित - एन्क्रिप्ट नहीं किया गया)
- मॉड्यूल प्रगति और लेनदेन आईडी (स्थानीय रूप से `~/.xrpl-lab/state.json` में संग्रहीत, tmp + नाम बदलने के माध्यम से परमाणु लेखन)
- एक्सआरपीएल टेस्टनेट आरपीसी (सार्वजनिक समापन बिंदु, सबमिशन से पहले स्थानीय रूप से हस्ताक्षरित लेनदेन)
- टेस्टनेट फ़ॉसेट (सार्वजनिक HTTP, केवल आपका पता भेजा जाता है)

**एक्सआरपीएल लैब द्वारा उपयोग नहीं किए जाने वाले डेटा:**
- कोई मेननेट नहीं। केवल टेस्टनेट
- कोई टेलीमेट्री, विश्लेषण या किसी भी प्रकार का फोन-होम नहीं
- कोई क्लाउड खाता, पंजीकरण या तृतीय-पक्ष एपीआई नहीं
- प्रमाण पैक, प्रमाणपत्र, रिपोर्ट या सहायता बंडल में कभी भी कोई गुप्त जानकारी नहीं

**अनुमतियाँ और भंडारण स्तर:**
- होम `~/.xrpl-lab/` - निजी गुप्त जानकारी स्तर, 0o700 निर्देशिका + 0o600 वॉलेट फ़ाइल। इसमें वॉलेट सीड, डॉक्टर लॉग, ऑडिट पैक संग्रहीत हैं।
- कार्यक्षेत्र `./.xrpl-lab/` - डिज़ाइन किया गया साझा करने योग्य स्तर, 0o755 निर्देशिका। इसमें मॉड्यूल रिपोर्ट, प्रमाण पैक, प्रमाणपत्र संग्रहीत हैं। सुविधाकर्ता अनुमति बढ़ाए बिना समीक्षा कर सकते हैं।
- फ़ाइल सिस्टम: केवल उपरोक्त दो स्थानों को पढ़ता/लिखता है
- नेटवर्क: केवल एक्सआरपीएल टेस्टनेट आरपीसी + फ़ॉसेट (दोनों पर्यावरण चर के माध्यम से ओवरराइड करने योग्य, दोनों `--dry-run` के साथ वैकल्पिक)
- किसी भी उन्नत अनुमति की आवश्यकता नहीं है

**डैशबोर्ड सतह (जब `xrpl-lab serve` चल रहा हो):**
- वेबसॉकेट रनर समापन बिंदु एक मूल अनुमत सूची लागू करता है (गैर-अनुमत कनेक्शन को कोड 4003 के साथ बंद कर देता है)
- सभी त्रुटि फ़्रेम एक संरचित लिफाफे का उत्सर्जन करते हैं (`code`, `message`, `hint`, `severity`, `icon_hint`) - कोई पथ रिसाव नहीं, कोई आंतरिक-अवस्था रिसाव नहीं
- प्रलेखित बैक-प्रेशर व्यवहार के साथ प्रति-कनेक्शन संदेश कतार सीमित है

पूर्ण सुरक्षा नीति और कार्यशाला सेटअप मार्गदर्शन के लिए [SECURITY.md](SECURITY.md) देखें।
